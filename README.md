# Vivir en Internet 🌐

![Logo de Semillero Digital](LOGO-SEMILLERO.png)

**Vivir en Internet** es una experiencia web interactiva desarrollada como parte del programa en **Semillero Digital**. El proyecto busca concientizar a los usuarios sobre la alfabetización digital, el pensamiento crítico y el bienestar en el entorno online a través de una serie de aplicaciones y juegos integrados en una única plataforma.

## 🚀 Módulos del Proyecto

La aplicación se divide en tres experiencias principales:

1.  **Detective Digital (DetectiveApp):** Un desafío de búsqueda y verificación de información donde el usuario debe poner a prueba sus habilidades de investigación para resolver casos.
2.  **Maestro de Prompts (PromptApp):** Una herramienta educativa para aprender a interactuar de manera efectiva con inteligencias artificiales, optimizando la comunicación hombre-máquina.
3.  **Bienestar Digital (WellbeingApp):** Un juego interactivo ("El Juego de la Batería") que simula el agotamiento de energía causado por las notificaciones y el uso excesivo de dispositivos, fomentando pausas saludables.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando tecnologías modernas de desarrollo web *front-end*:

* **HTML5:** Estructura semántica de la aplicación.
* **Tailwind CSS:** Framework de estilos para un diseño responsivo, moderno y "mobile-first".
* **JavaScript (Vanilla):** Lógica de los juegos, manejo del estado y animaciones interactivas.
* **Lucide Icons:** Conjunto de iconos vectoriales para una interfaz clara e intuitiva.

## 💻 Instalación y Uso

No requiere de servidores ni instalaciones complejas. Para ejecutar el proyecto localmente:

1. Clona este repositorio o descarga los archivos.
2. Asegúrate de que el archivo `index.html` y `logo-semillero.png` estén en la misma carpeta.
3. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, etc.).

## 🎯 Objetivo de Aprendizaje

Este proyecto fue diseñado para demostrar habilidades en:
* Desarrollo de lógica de programación con JavaScript.
* Diseño de interfaces de usuario (UI) centradas en la experiencia del usuario (UX).
* Creación de contenidos educativos interactivos para entornos digitales.
